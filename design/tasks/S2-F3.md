# S2-F3: headless Blender roof checks

Owner: dev · sprint S2 · **v0.3.0 blocker** (cheap) · recorded in
[S2-REVIEW](../reviews/S2-REVIEW.md)

## Problem

The headless Blender harness (`tests/blender/`) covers core output, bridges, tunnels and
passages, but not roofs. S2-ROOF (#18) is tested only in Python. Nothing confirms that the
Blender add-on path produces the same closed roofs.

## Acceptance criteria

1. A new `tests/blender/checks_roofs.py`, picked up by `run_integration.py` like the other
   `checks_*` modules, generates the synthetic fixture inside Blender. For each roof shape
   present in the fixture, it asserts:
   * the **building** object is found by its `mb_id`. Roofs are not separate objects: the
     generator adds roof faces to the building mesh (`core/generate.py` → `roofs.build_roof`);
   * that mesh has roof faces, identified as faces with a vertex above the wall top
     (`eave_height_m` in the provenance) or faces using the `MB Roof` material. Gable ends use
     `MB Facade`, so the height test is the primary one;
   * the whole building mesh (walls + roof) is closed (no boundary edges);
   * the roof apex or ridge height matches the Python pipeline's value within 1 mm.
2. At least one unsupported `roof:shape` falls back to flat in Blender, with the same report
   reason as in Python.
3. A headless Blender 4.2.23 run gives `OK: 0 failure(s)`. Append the result to
   `docs/VALIDATION.md`.
4. If the fixture lacks a shape the checks need, append it to `tests/fixtures/synthetic_area.osm`
   (soft, D20) and regenerate `examples/synthetic_sample.mbmap`.

## Performance considerations

The harness is local-only (no Blender in PR CI). Adding the roof checks should add ≤ 10 s to
the headless run. PR CI is unchanged.

## Conflict domain

Hard: `tests/blender/checks_roofs.py` (new), plus a one-line registration in `run_integration.py`
if modules are not auto-discovered. Soft: `tests/fixtures/synthetic_area.osm` (append-only),
`examples/synthetic_sample.mbmap`, `docs/VALIDATION.md` "Recorded results".
