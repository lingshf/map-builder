# S3-TEX-ASSETS: procedural CC0 texture set

Owner: dev · sprint S3 · wave 1 · D56

## Goal

A small set of tileable textures generated by our own script and dedicated to CC0, committed
as package data. There is no runtime generation and no third-party imagery. Google and other
map imagery is forbidden (D2).

## Scope

* `tools/textures/make_textures.py`: a deterministic, seeded generator using pure Python
  `zlib`/`struct` PNG writing (no new dependencies). It produces 256×256 or 512×512 RGB PNGs
  for:
  * facade (plaster, with a window-grid hint);
  * roof tiles;
  * flat roof (gravel);
  * asphalt with lane-agnostic noise;
  * terrain (grass/soil noise);
  * concrete.
* Output goes to `map_builder/assets/textures/*.png`, plus a `LICENSE-textures.txt` with the
  CC0 1.0 dedication and the generator command.
* `core/textures.py`: a table mapping material name → (png file, tile size in metres,
  roughness), plus `load(name) -> bytes` via `importlib.resources`. These files ship in the
  extension zip.

## Acceptance criteria

1. Running the generator twice gives byte-identical PNGs, and a test checks their SHA-256
   against the committed files.
2. Every PNG is power-of-two, ≤ 512 px and passes the S3-TEX-FORMAT PNG header check, once
   that task is merged; until then a local check is used.
3. Total texture bytes are ≤ 2 MiB, a counted test (D60).
4. The extension zip built as in `.github/workflows/release.yml` (`blender --command extension
   build`) contains the textures. This is a test on the zip file list.
5. `LICENSE-textures.txt` and the README "Data and licences" section name the textures as
   CC0 / own work.

## Performance considerations

There is no runtime cost beyond reading the bytes. The generator is offline. The tests only
hash files, ≤ 1 s.

## Conflict domain

Hard: `tools/textures/**` (new), `map_builder/assets/textures/**` (new), `core/textures.py`
(new), `tests/test_textures.py` (new). Soft: README licence section, `blender_manifest.toml`
(only if the build would otherwise exclude `assets/`).
